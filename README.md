# Members Only
## Link
https://members-only-production-d654.up.railway.app/

## Description
An ExpressJS message application that allows you to sign up/login and post messages with varying levels of permission. If you are
a user, you can post messages, if you are a member you can message metadata, and if you become an admin you can delete other people's messages. To get started just click the link above! To become a member enter "May the force be with you".

## Reflection
This was an interesting ExpressJS application that leveraged [passport.js](https://www.passportjs.org/) to handle authentication.
It was interesting getting that setup and figuring out how I wanted different levels of users to be able to have different functionality and dynamic changes to the HTML content I served depending on their role. Furthermore, it was good practice with ExpressJS, Embedded JavaScript, working with Model-View-Controller (MVC) architecture, and interacting with a PostegreSQL database along with all of my other prior web development skills such as HTML/CSS and JS.
